# Smart Farm+ 0.7.6

- บันทึกอุปกรณ์ Output และสถานะเปิด/ปิดถาวร
- บันทึกการเพิ่ม แก้ไข ลบ และเปิด/ปิดเซ็นเซอร์
- เพิ่มหน้าเลือกเซ็นเซอร์ที่รองรับ
- แสดง INPUT ที่ควรใช้และคำแนะนำการต่อสาย
- กำหนด I2C BUS, DI1-DI4 และ AI1-AI2 แบบ Logical Input
- I2C แชร์บัสได้ ส่วน Digital/Analog ป้องกันการใช้ INPUT ซ้ำ
- เตรียม Hardware Mapping สำหรับ ESP32 V1
