# Changelog

## 0.7.5 - Core Foundation

- Added global Light, Dark and System themes.
- Added Thai and English app locale foundation.
- Added persistent settings using SharedPreferencesAsync.
- Farm name, controller, Wi-Fi, notification, time, theme and language now persist.
- Added one global SettingsStore shared by the entire app.
- Updated main navigation, splash, settings, devices and sensors for localization.
- Updated app version to 0.7.5+15.
